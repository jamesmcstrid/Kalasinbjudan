# Kalasinbjudan

En enkel digital inbjudan till barnkalas med OSA-funktion.

## Funktioner

- Responsiv design med Tailwind CSS
- OSA-formulär med Firebase/Firestore
- Realtidsuppdaterad gästlista
- Kalender-integration (Google Calendar, Apple/Outlook)
- Allergi-hantering

## Teknologi

- HTML/CSS/JavaScript
- Tailwind CSS
- Firebase Firestore
- Font Awesome ikoner
